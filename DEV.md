# Среда разработки ПО для микроконтроллеров STM32

## Официальная экосистема STMicroelectronics

### 1. STM32CubeIDE (Рекомендуемая)

**Тип:** Интегрированная среда разработки (IDE)  
**Статус:** Бесплатная, официальная  
**Платформы:** Windows, Linux, macOS

**Описание:** Официальная бесплатная IDE от STMicroelectronics на базе Eclipse и GNU MCU Eclipse. Объединяет в себе STM32CubeMX для настройки периферии и генерации кода с полнофункциональной средой отладки.

**Ключевые особенности:**
- Встроенный STM32CubeMX для визуальной конфигурации
- Автоматическая генерация кода инициализации на C
- Поддержка всех микроконтроллеров STM32
- Интегрированный отладчик (GDB) с поддержкой ST-Link, J-Link
- Продвинутые возможности отладки: Live Watch, Serial Wire Viewer (SWV)
- Поддержка ОСРВ (FreeRTOS) в отладчике

**Ссылка:** [https://www.st.com/en/development-tools/stm32cubeide.html](https://www.st.com/en/development-tools/stm32cubeide.html)

---

### 2. STM32CubeMX

**Тип:** Инструмент конфигурации и генерации кода  
**Статус:** Бесплатный, официальный  
**Платформы:** Windows, Linux, macOS

**Описание:** Отдельный графический инструмент для начальной настройки проекта. Генерирует код инициализации для различных IDE.

**Ключевые особенности:**
- Визуальное конфигурирование пинов и тактовой частоты
- Конфигурация периферии (UART, SPI, I2C, ADC и т.д.)
- Настройка middleware (USB, TCP/IP, графические библиотеки)
- Генерация кода для STM32CubeIDE, Keil, IAR, Makefile
- Расчет потребления энергии

**Ссылка:** [https://www.st.com/en/development-tools/stm32cubemx.html](https://www.st.com/en/development-tools/stm32cubemx.html)

## Сторонние коммерческие IDE

### 3. Keil MDK (Microcontroller Development Kit)

**Тип:** Коммерческая IDE  
**Статус:** Платный (есть бесплатная версия с ограничением 32 КБ)  
**Платформы:** Windows

**Ключевые особенности:**
- Высокооптимизирующий компилятор ARM Compiler
- Отличная интеграция с отладочными пробниками (ULINK)
- Продвинутые средства отладки и анализа кода
- Поддержка CMSIS-Pack
- Жесткие реального времени

**Ссылка:** [https://www.keil.com/](https://www.keil.com/)

### 4. IAR Embedded Workbench for ARM

**Тип:** Коммерческая IDE  
**Статус:** Платный (есть бесплатная версия с ограничением)  
**Платформы:** Windows

**Ключевые особенности:**
- Очень высококачественная оптимизация компилятора
- Мощные инструменты статического анализа кода (C-STAT)
- Интегрированная проверка безопасности (C-RUN)
- Подробный анализ использования стека и памяти

**Ссылка:** [https://www.iar.com/](https://www.iar.com/)

## Решения на основе Open Source

### 5. PlatformIO

**Тип:** Кроссплатформенная экосистема  
**Статус:** Бесплатный  
**Платформы:** Windows, Linux, macOS

**Описание:** Мощное расширение для Visual Studio Code для автоматизации сборки, загрузки и отладки.

**Ключевые особенности:**
- Единая среда для разных плат и фреймворков (HAL, LL, Arduino)
- Менеджер библиотек и интегрированный отладчик
- Система сборки на основе CMake
- Поддержка Unit-тестирования
- Огромное сообщество

**Ссылка:** [https://platformio.org/](https://platformio.org/)

### 6. Arduino IDE (с поддержкой STM32)

**Тип:** Упрощенная среда для прототипирования  
**Статус:** Бесплатный  
**Платформы:** Windows, Linux, macOS

**Ключевые особенности:**
- Очень низкий порог входа
- Огромное количество готовых библиотек
- Идеально для хобби-проектов
- Использует упрощенный Arduino API поверх HAL

## Профессиональные текстовые редакторы

### 7. Visual Studio Code + Расширения

**Тип:** Текстовый редактор с расширениями  
**Статус:** Бесплатный  
**Платформы:** Windows, Linux, macOS

**Необходимые расширения:**
- **C/C++** (от Microsoft) - интеллектуальное завершение кода
- **Cortex-Debug** - отладка микроконтроллеров ARM
- **CMake Tools** (для работы с CMake)

**Системы сборки:** Makefile, CMake, Arm GNU Toolchain
