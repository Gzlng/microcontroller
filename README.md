# Компонентная база STM32

1. **Сердце системы:**

* Ядро (Core)

*Назначение: Это центральный процессор (CPU) микроконтроллера. Он выполняет код вашей программы, производит вычисления и управляет всеми остальными компонентами.*

**Варианты в STM32:**

    Cortex-M0/M0+: Низкое энергопотребление и стоимость, для простых задач.

    Cortex-M3: Баланс производительности и эффективности, самый популярный для широкого круга задач.

    Cortex-M4: Высокая производительность, часто имеет блок FPU (Floating Point Unit) для ускорения вычислений с плавающей запятой, что критично для цифровой обработки сигналов (DSP).

    Cortex-M7: Высокопроизводительное ядро для сложных задач (например, продвинутые интерфейсы, сложные алгоритмы).

    Cortex-M33: Современное ядро с поддержкой безопасности (TrustZone).

2. **Память**

* Flash-память:

*Назначение: Хранение программы (прошивки), констант, неизменяемых данных. Это "жесткий диск" микроконтроллера. После выключения питания данные сохраняются.*

* SRAM-память (ОЗУ):

*Назначение: Хранение временных данных: переменных, стека, буферов во время выполнения программы. Быстрая, но volatile-память (данные теряются при отключении питания).*

* EEPROM (есть не во всех моделях):

*Назначение: Хранение данных, которые должны сохраняться после отключения питания и могут часто меняться (например, настройки пользователя, счетчики). Выдерживает больше циклов записи, чем Flash.*

3. **Тактовая система (Clock System)**
*Назначение: Генерация тактовых импульсов для синхронизации работы ядра и периферии. Можно представить как дирижера оркестра.*

**Компоненты:**

    Внутренние генераторы (HSI, LSI, MSI): Неточные, но дешевые и энергоэффективные. Используются для watchdog-таймеров или как резервный источник.

    Внешние кварцевые резонаторы (HSE, LSE): Точные. HSE — для высокой производительности ядра, LSE — для часов реального времени (RTC).

    PLL (ФАПЧ): Умножает частоту внутреннего или внешнего генератора, чтобы получить высокую тактовую частоту для ядра.

4. **Система питания (Power Supply)**
*Назначение: Формирование и распределение необходимых напряжений для разных блоков микроконтроллера. Позволяет переходить в режимы пониженного энергопотребления (Sleep, Stop, Standby).*

5. **Периферийные устройства (Самая обширная часть)**
*Это "органы чувств" и "руки" микроконтроллера, которые взаимодействуют с внешним миром.*

**Цифровая периферия:**

* GPIO (General Purpose Input/Output):

*Назначение: Универсальные выводы, которые можно программно настроить как вход (читать напряжение с кнопки, датчика) или как выход (подать напряжение на светодиод, управлять транзистором).*

**Таймеры (TIM):**

*Назначение: Одна из самых гибких периферий. Используются для:*

* Генерации ШИМ (PWM): Управление скоростью моторов, яркостью светодиодов.

* Измерения длительности импульсов (например, с энкодера).

* Создания точных временных интервалов.

* Счета внешних событий.

**USART/UART (Универсальный асинхронный приемопередатчик):**

*Назначение: Последовательный интерфейс для обмена данными с компьютерами, GPS-модулями, Bluetooth-модулями и другими устройствами по протоколу UART.*

**SPI (Serial Peripheral Interface):**

*Назначение: Высокоскоростной синхронный последовательный интерфейс для связи с периферийными чипами: SD-карты, LCD-экраны, Flash-память, датчики.*

**I²C (Inter-Integrated Circuit):**

*Назначение: Двухпроводной последовательный интерфейс для связи с множеством устройств на одной шине. Медленнее SPI, но требует меньше выводов. Используется для датчиков (температура, давление), EEPROM, RTC.*

**USB (Universal Serial Bus):**

*Назначение: Подключение к компьютеру для передачи данных, создания виртуальных COM-портов, реализации USB-устройств (клавиатура, мышь) или хостов (чтение флешек).*

**CAN (Controller Area Network):**

*Назначение: Надежный сетевой интерфейс для промышленных и автомобильных применений. Устойчив к помехам.*

**Ethernet MAC:**

*Назначение: Подключение к локальной сети (LAN). Требует внешнего PHY-чипа.*

**Аналоговая периферия:**

* **АЦП (ADC - Analog-to-Digital Converter):**

*Назначение: Преобразует аналоговое напряжение (например, с потенциометра, терморезистора, микрофона) в цифровое число, которое может обработать процессор. Основа для взаимодействия с аналоговым миром.*

* **ЦАП (DAC - Digital-to-Analog Converter):**

*Назначение: Преобразует цифровое число в аналоговое напряжение. Используется для генерации звука, управляющих сигналов и т.д.*

* **Компаратор (Comparator):**

*Назначение: Сравнивает два аналоговых напряжения и выдает цифровой сигнал ("1" или "0") в зависимости от того, какое напряжение больше. Работает очень быстро.*

**Специализированная периферия:**
* **DMA (Direct Memory Access):**

*Назначение: Позволяет периферийным устройствам обмениваться данными с памятью без участия ядра. Ядро в это время может выполнять другой код или спать, экономя энергию. Крайне важный блок для эффективности.*

* **Контроллер прерываний (NVIC):**

*Назначение: Обрабатывает запросы от периферии на немедленное внимание процессора. Когда наступает событие (например, пришел байт по UART или сработал таймер), NVIC "прерывает" основную программу и заставляет процессор выполнить специальную функцию-обработчик (ISR).*

* **RTC (Real-Time Clock):**

*Назначение: Часы реального времени, которые продолжают отсчет времени даже когда основной процессор отключен (от отдельного источника питания, например, батарейки).*
